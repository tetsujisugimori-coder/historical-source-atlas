# 永享記：史料記事データベース試作（v0.2）

## ファイル
- `index.html`：スマートフォン／PCで直接開ける閲覧用Web年表（ネットワーク接続なしでも絞り込み可能）。
- `eikyouki.db`：`python build.py`で生成するSQLiteデータベース。史料／版／章段／記事を分離。
- `schema.sql`：SQLiteスキーマ。別史料追加時は新しい作品・版のIDを登録する。
- `eikyouki_records.json`：サンプル15記事と出典情報。
- `build.py`：上記を再作成するPythonスクリプト。
- `test_dates.py`：暦変換・記録の整合性を検査。

## 試作の範囲と重要な制限
- 登録対象は『永享記』からの **15件の個別記事候補**。章段や事件単位にまとめない。
- 原資料は近藤瓶城編『史籍集覧』第12冊に基づくWikisource版。URL: https://ja.wikisource.org/wiki/永享記
- 項目の要約・短い日付手掛かりのみ採録し、原文全文転記は未着手。収録データは校訂済み本文とみなさない。
- `western_year` は**年号と対応する西暦年**のみ。`lunar_month` と `lunar_day` は**和暦の日付**で、グレゴリオ暦の月日とは異なる。
- `julian_start/end` は暦日対照表から参照したユリウス暦日付（両端を含む）。`gregorian_start/end` はそれらを**先発グレゴリオ暦**に換算した日付。日付の明示は開始＝終了、月・年のみなら範囲を保存。
- `historic_calendar` は当時用いられた宣明暦を記録する。閏月用の `lunar_is_leap` を別欄に置き、通常月と取り違えない。
- 換算値はすべて `date_conversion_status=provisional`。**暦日対照表（Gozaaru）のユリウス暦欄を確認したうえでの暫定換算であり、国立天文台との暦日独立照合は旧レビュー5793714253に履歴あり。今回の新規照会や本文校訂完了を意味しない。** 将来の修正履歴の保存が必要。
- `research_date_start/end/basis` は史料上の日付と異なる研究上の推定年代専用（現在はすべて NULL）。
- 本文の「同年」「同月」等は文脈補完の記録付き。近代的な地名・座標や史実評価を勝手に挿入しない。
- 史料本文の内容には誇張、錯誤、伝本差があり得る。本文記述と確定史実は区別する。
- 紹介論文・各伝本との照合、史料所在ページ範囲の確定、原文転記は今後の工程。
- 閲覧Webアプリ内のJSON書き出しは表示中のデータのコピーで、SQLiteへの書き戻しではない。

## IDと重複の原則
- `article_id` は一記事の恒久ID。`source_order` は章段またぎの資料掲載順。
- 同じ年に10記事あれば10行、同じ事件が別史料に記載されていれば別の行を作成。
- 将来イベント関連付けが必要でも、別の `article_relationships` テーブルで関連を表現し、元の記事を統合しない。
- 同一記事の訂正・原文増補と、新規独立記事の追加は区別する。

## 暦換算の出典と方法
- 暦日対照表: https://reki.gozaaru.com/wareki/永享/8 ・ https://reki.gozaaru.com/wareki/永享/9 ・ https://reki.gozaaru.com/wareki/永享/10 （**民間サービス・暫定**）。
- 先発グレゴリオ暦換算は、ユリウス暦の日付をいったんユリウス日番号へ変換し、グレゴリオ暦の年月日へ戻す算術処理を行う。15世紀だけに通用する固定日数の加算を汎用処理として使わない。
- 国立天文台 暦計算室: https://eco.mtk.nao.ac.jp/cgi-bin/koyomi/caldb.cgi （同DBは1582年以前にユリウス暦を標準表示。正式な暦日照合の参照先）。
- 史料原文の「同月」「同年」などの文脈による補完は、暦換算結果とは別の不確実性として残す。本文未照合のため15記事の史実日付が確定したわけではない。

## PR #1 修正後の保存・検証契約

[根本修正と再現手順](../../docs/pr1-remediation.md)を参照。SQLite 3.37以降（STRICT表）が必要です。
`test_dates.py`と`run_checks.py`は既存DBを読み取り専用で検査し、自動再生成しません。
入力の所属・出典・型・暦日・精度を生成前に検査します。非対応の資料所属は明示拒否します。
日付順は換算開始日、同日は掲載順→ID、日付不明は末尾。史料掲載順は別に維持します。
月朔による検証は旧独立レビューの国立天文台照合履歴を根拠とする永享8〜10年に限り、範囲外は未解決として保持します。
unknown/unresolvedとNULLは不正入力と区別します。start=endは日付点の精度で、事件の終息日認定ではありません。
既存15件の換算値・恒久ID・原文手掛かり・要約・全文NULLは保持し、研究推定は依然NULLです。
