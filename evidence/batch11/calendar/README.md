# Batch 11 暦換算証拠

国立天文台 暦計算室「日本の暦日データベース」の結果を、2026-11-10 UTC に取得した。元号識別子は既存の公式応答にある選択肢で嘉吉=b209、享徳=b212と確認し、各和暦を別々に照会した。

| 和暦入力 | ユリウス暦（jg=0） | 先発グレゴリオ暦（jg=1） |
| --- | --- | --- |
| 嘉吉元年六月二十四日 | 1441-07-12 | 1441-07-21 |
| 享徳三年十二月二十七日 | 1455-01-15 | 1455-01-24 |

`naoj-*-0.html` は「西暦の日付はすべてユリウス暦によります」、`naoj-*-1.html` は「西暦の日付はすべてグレゴリオ暦によります」と明示する公式応答。4件ともHTTP 200。各応答の元バイト列（EUC-JP）を変換せず保存した。`retrieval.json` に完全な要求URL、最終URL、HTTP状態、取得開始・終了日時、レスポンスヘッダー、バイト数、SHA-256、および結果部分の文字抽出を記録した。保存後、4件のハッシュとHTTP状態を再検証した。

## 解釈上の限界

- これは指定和暦の日付換算の確認であり、記事の事件が実際にその日に起きたという歴史的認定ではない。
- 西暦は暦の種類を明示する。1582年以前なので、jg=1の結果は先発グレゴリオ暦であり、当時使用された暦という意味ではない。
- 享徳三年十二月二十七日は旧暦年と西暦年の境界を越え、両西暦表示とも1455年となる。享徳三年を機械的に1454年の西暦日に置換してはいけない。
- 独立した別の和暦原典による再計算は行っていない。国立天文台の当該応答には参考文献として内田正男『日本暦日原典』等が挙げられているが、これらの紙面は未確認。
- 公式サイト自身が予告なく変更することがあると記している。ここでの証拠は記録日時に取得した応答である。
