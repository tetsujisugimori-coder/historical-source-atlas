# Historical Source Atlas（史料基点の資料）

歴史史料の**記事を一件ずつ**収集・整理し、年表や地図などの表示へつなげるオープンな試作プロジェクトです。最初の題材は『永享記』です。

## データ管理の原則

1. 一年に複数の記事があれば、それぞれ独立したレコードとして登録します。
2. 同じ事件が複数の史料に記されていても、記事を統合しません。相互の関係は別テーブルで管理します。
3. 本文・出典・原文の日付と、現代語の要約・研究上の推定を区別します。
4. 史料に記された和暦、先発グレゴリオ暦への換算年月日（または期間）、研究上の推定日付を別項目で保持します。換算根拠・確認状況を残します。
5. 根拠が不足する地理的位置・日付・史実認定は確定値として扱いません。

```sh
python prototype/eikyouki/build.py
python prototype/eikyouki/test_dates.py
```

**ご注意：** 現在の117件は史料記事の「仮登録候補」です。全文翻刻や伝本・原画像との照合は未了で、暦換算も暫定値です。展示・研究で確定した史実として再利用しないでください。

## 開発状況

このリポジトリは初期試作です。公開リポジトリですが、公開は内容の学術的検証を意味しません。地図連携・記事増補・出典検証・校訂管理は今後の検討対象です。
